# 局域网分享 Implementation Plan

> 设计文档：`docs/superpowers/specs/2026-11-13-lan-share-design.md`（协议、命令契约、数据结构以设计文档为准）

**Goal:** 在 ws-workbench 增加「局域网分享」工具页：局域网内互相发现运行本应用的设备，确认后接收 / 发送文件，接收目录可配置。

**Architecture:** Rust 侧新增 `lanshare` 模块（`std` 实现 UDP 组播发现 + 明文 HTTP 文件传输，无新增第三方依赖），通过 7 个 Tauri 命令和 2 个事件暴露给前端；前端新增独立工具页，图标栏入口 + 快捷键 5。

**Tech Stack:** Tauri 2 / Rust（std net、serde、uuid、chrono）、Vue 3 + ant-design-vue、tauri-plugin-store。

### Task 2: UDP 组播发现

**Files:** Create `src-tauri/src/lanshare/discovery.rs`；Modify `mod.rs`（启动/停止接线）

- [ ] 绑定 `0.0.0.0:53317`（失败尝试 53318..53326）；`set_multicast_loop_v4(true)`、`set_multicast_ttl_v4(1)`、`join_multicast_v4` 到 `netinfo` 拿到的每个本机 IPv4（忽略单个失败）

- [ ] 读超时 500ms + `AtomicBool` 停止；peer 变化推送 `lan-share://snapshot`（限速 ≤1 次/秒）

### Task 3: HTTP 接收服务

**Files:** Create `src-tauri/src/lanshare/server.rs`；Modify `mod.rs`

- [ ] `TcpListener` 监听端口，每个连接一个线程；手写 HTTP/1.1 解析（请求行 + headers + `Content-Length`，上限 headers 64KB、prepare 请求体 2MB）
- [ ] `GET /api/lanshare/v1/info`、`POST /api/lanshare/v1/prepare-upload`（登记 offer、推送快照、`mpsc` 等待 ≤60 秒、接受后生成 session+token）、`POST /api/lanshare/v1/upload`（校验 session/file/token/大小，流式写 `.part` 再改名）、`POST /api/lanshare/v1/cancel`
- [ ] 会话 5 分钟过期清理；重复 `prepare` 不阻塞监听；错误码按设计文档
- [ ] `respond_offer(offer_id, accept)` 由命令层调用
- [ ] 单测：拒绝 → 403、超时 → 408、接受 → 上传成功且文件内容一致；路径穿越文件名不会写出目录
