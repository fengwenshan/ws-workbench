- [ ] **Step 2: 实现执行**

`uninstall(app: &InstalledApp) -> UninstallOutcome`：

1. 解析 `UninstallString`；`msiexec` + ` /I{` → `/X{`
2. 生成 PowerShell：`Start-Process -FilePath '<program>' -ArgumentList @('<arg1>','<arg2>') -Wait -PassThru`；`needs_elevation` 时加 `-Verb RunAs`

4. 退出码非 0 → `ok=false`；PowerShell 超时 → `message="卸载程序超时（15 分钟）"`
