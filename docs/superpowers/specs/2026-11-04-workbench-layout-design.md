# 多工具工作台布局 设计文档

- 日期：2026-11-04
- 分支：feat/vpn
- 状态：待评审
- 关联：无（纯前端布局重构，不改业务逻辑与存储）

## 1. 背景与目标

应用已经是一个多工具桌面程序：项目分组/打包、代理（VPN）、设置、日志。但当前布局只有「主页 = 固定 240px 项目树 + 详情」，代理/设置/日志是整页替换的子页，只能从托盘或「返回」按钮进出，没有全局工具导航，窗口变宽后项目树和详情区的空间分配也不合理。

本次把主界面改成 VS Code 式三栏工作台，把日志从独立页改成工作区底部面板。

### 目标（In Scope）

1. 左侧 56px 常驻图标栏：项目 / 代理 / 设置三个工具，底部是 VPN 状态与日志开关；`⌘/Ctrl+1/2/3` 切换工具。
2. 项目树面板：200–420px 可拖拽、可折叠、宽度与折叠状态持久化（`⌘/Ctrl+B`）。
3. 工作区：按工具切换项目详情 / 代理 / 设置，用 `v-show` 保留状态。
4. 日志面板：工作区底部，默认收起，120px–50vh 可拖拽，`⌘/Ctrl+J` 开关，持久化高度与开合状态。
5. 38px 标题栏承载窗口拖动、当前工具名、版本号与更新按钮（macOS 红绿灯区域留白）。
6. 窄窗口（< 900px）自动隐藏项目树；< 720px 日志面板覆盖在工作区上。
7. 视觉风格、颜色变量、组件内部样式与交互（ProjectList 拖拽、VpnPanel、SettingsPanel）保持不变。

### 非目标（Out of Scope）

- 不改业务逻辑、命令、数据存储、`ProjectList` / `VpnPanel` / `SettingsPanel` 组件内部实现。
- 不做深色模式、命令面板、多窗口、工具页签拖拽、自定义主题。
- 不重做项目详情/代理/设置页的内容布局，只换外层容器。

## 2. 布局结构

```text
┌──────────────────────────────────────────────────────────────┐
│ Titlebar 38px（macOS 左留 78px 红绿灯）  [当前工具] [版本][更新]│
├────┬──────────────────┬──────────────────────────────────────┤
│图  │ 项目树面板        │ 工作区                                │
│标  │ 200–420px        │ 项目详情 / 代理 / 设置                │
│栏  │ 可折叠、宽度记忆  │                                      │
│56px│                  ├──────────────────────────────────────┤
│    │                  │ 日志面板（可折叠、高度可拖）           │
└────┴──────────────────┴──────────────────────────────────────┘
```

- `.rail`：56px，顶部工具按钮（40×40 命中区，active 左侧高亮条），底部 VPN 状态点（灰/绿/脉冲）与日志开关。
- `.tree-panel`：仅「项目」工具显示；外层容器控制宽度，不自带标题（沿用 `ProjectList` 自带表头），右上角浮一个折叠按钮。
- `.workspace`：`flex:1`，内部依次是更新横幅、当前工具内容、日志分隔条、日志面板。
- `.log-panel`：`LogPanel` 复用，头部是「应用 / VPN」切换、清空、关闭。
- `.titlebar`：`data-tauri-drag-region`，macOS 下 `padding-left: 78px`。

## 3. 交互与状态

| 操作 | 行为 |
| --- | --- |
| 点击图标栏「项目」 | 不在项目页则切到项目页并展开树；已在项目页则折叠/展开树 |
| 点击「代理 / 设置」 | 切换工作区内容，树面板隐藏 |
| `⌘/Ctrl+1/2/3` | 切换到项目 / 代理 / 设置 |
| `⌘/Ctrl+B` | 折叠/展开项目树 |
| `⌘/Ctrl+J` | 打开/关闭日志面板 |
| 拖拽项目树右缘 | 宽度 200–420px，松手写入 localStorage |
| 拖拽日志面板上缘 | 高度 120px–50vh，松手写入 localStorage |
| 双击项目树分隔条 | 恢复默认宽度 260px 并展开 |
| 双击日志分隔条 | 恢复默认高度 220px |
| 托盘「代理 / 设置 / 日志」 | 前两者切换工具，日志项打开底部面板 |
| 点击 VPN 状态点 | 切到代理页 |

状态持久化键（`safeStorage` 密文写入）：`ws-workbench:layout:tree-width`、`ws-workbench:layout:tree-collapsed`、`ws-workbench:layout:log-height`、`ws-workbench:layout:log-open`。

响应式：< 900px 隐藏树面板与分隔条；< 720px 日志面板改为 `position:absolute` 覆盖在工作区底部，带顶部分隔条与阴影。

## 4. 实现要点

- `App.vue` 只重组模板与样式；脚本新增布局状态、拖拽/双击处理、快捷键监听与托盘映射调整。
- 布局状态读写复用 `src/composables/safeStorage.ts`（符合本地存储加密规则）。
- 快捷键监听在 `onMounted` 注册、`onUnmounted` 移除；焦点在 `input` / `textarea` / `[contenteditable]` 内时忽略。
- 更新按钮与版本号从原侧栏底部移到标题栏；更新横幅保留在工作区顶部。
- 删除 `.subpage` / `.back-btn` / `.window-drag-box` / `.sidebar` / `.update-bar` 等旧样式；保留弹窗、表单、`no-selection` 样式。

## 5. 验收标准

1. 图标栏可在三个工具间切换，当前工具高亮正确，`⌘/Ctrl+1/2/3` 生效。
2. 项目树可拖拽（200–420px）、可折叠（`⌘B`），刷新/重启后宽度与折叠状态恢复。
3. 日志面板可开合（图标、`⌘J`、托盘）、可拖拽高度，重启后状态恢复；切换应用/VPN 日志与清空正常。
4. 切换工具时 VPN 连接状态与日志流不中断（`v-show` 生效）。
5. 宽度 < 900px 时树面板自动消失；< 720px 时日志面板覆盖显示。
6. macOS 上标题栏可拖动窗口、红绿灯不被遮挡；Windows 下标题栏无异常留白。
7. `pnpm build` 通过；`cargo test --lib` 与改动前一致（无新增失败）。
