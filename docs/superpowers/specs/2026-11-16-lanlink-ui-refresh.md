# LANLink · 界面与设置刷新（第二轮）

日期：2026-11-16
基线：`1258496`（beta 分支，会话体验增强已交付）

## 1. 需求清单（来自用户）

1. 设置页不要右栏标题与「返回聊天」，直接显示内容。
2. 本机设备名可修改，对端看到修改后的名字；对端若已备注，本机看到的仍是对端给的备注名。
3. 监听端口不允许关闭，除非应用退出（去掉「开启/关闭功能」）。
4. 去掉「接收文件前需要确认」功能（始终直接接收）。
5. 去掉「设备 ID 使用主物理网卡 MAC…」整段解释。
6. 监听端口 53317 显示在设备名后面，不再单独一行。
7. 聊天头部不显示绿色在线状态（左侧列表已有）。
8. 聊天头部 IP 不显示对方端口号。
9. 消息提示音改成 DeepSeek Harness `dsh-chime` 插件「任务完成」音效（`bip-bop-01.mp3`）。
10. 标题「LANLink」右侧放设置按钮；去掉左栏底部「设置 + 运行状态」。
11. 「局域网分享」更名为 **LANLink**（所有用户可见处）。
12. 模块整体现代化：背景、层次、阴影；右侧头部与聊天内容不用分割线，用悬浮阴影；提升整体档次。
13. 备注了对端时，IP 前面显示对方原本的设备名；没备注时只显示默认信息。

## 2. 视觉方向：Glass Deck（浅色 · 悬浮层）

目标：像一块悬浮在浅色玻璃台面上的「连接面板」，而不是灰底表格。左侧列表保持信息密度，右侧像浮起来的对话卡。

### 2.1 颜色

- 画布（模块底）：`linear-gradient(160deg, #f3f6fc 0%, #eef2f9 55%, #edf1f8 100%)`，左上叠一层极淡蓝紫光晕 `radial-gradient(60% 55% at 8% 0%, rgba(99,102,241,.10), transparent 70%)`。
- 左栏表面：`rgba(255,255,255,.55)` + `backdrop-filter: blur(18px)`，不用右边框。
- 右栏表面：`#fbfcfe`，与左栏之间用间距 + 阴影分层，不用分割线。
- 列表项（未选中）：透明；hover `rgba(255,255,255,.75)` + 轻微上浮；选中：`rgba(255,255,255,.95)` + `box-shadow: 0 1px 2px rgba(15,23,42,.05), 0 12px 28px -18px rgba(37,99,235,.45)` + 左侧 3px 主色圆角指示条（inset box-shadow 或伪元素）。
- 强调色沿用 `--primary: #3b82f6`；不新增品牌色，避免与整个应用冲突。
- 文本：`#0f172a` / `#64748b` / `#94a3b8`（可映射为 `--text-primary` / `--text-secondary` / `--text-muted`）。
- 阴影（唯一 elevation 体系）：
  - 低：`0 1px 2px rgba(15,23,42,.04)`
  - 中：`0 10px 30px -18px rgba(15,23,42,.28)`
  - 高（输入区/菜单）：`0 18px 45px -24px rgba(15,23,42,.35)`

- 左栏宽度 300px（窄窗 240px）；整块模块圆角 16px（若外层容器允许，否则只做内部卡片圆角）。
- 左栏标题：`LANLink` 字标（600~700 字重，letter-spacing .12em，主色小圆点或双节点图形作为标识），右侧齿轮按钮。
- 右栏头部：左侧头像 + 名字（备注编辑保留），第二行 `原名 · IP`（备注时）或 `IP`（无备注时）；右侧「发送文件 / 删除会话」按钮弱化为文字按钮/图标按钮；无下边框。
- 设置页：无任何标题、无「返回聊天」；内容顶部直接是「本机设备名 + 端口」卡片，依次 接收目录 / 消息提示音 / 本机地址 / 设备 ID；信息块用白色卡片悬浮，不再用 `dl` 分割线。
- 输入区：浮在底部的白色圆角卡（圆角 14px、中/高阴影、内边距 10px），去掉上边框；发送按钮保持主色。
- 动画：列表项 hover `translateY(-1px)`、选中背景过渡 160ms；`prefers-reduced-motion` 关闭位移。避免满屏动效。

### 2.3 文案

- 标题统一 `LANLink`；不要再出现「局域网分享」。
- 设备名行：`本机设备名 · 53317`（端口随 `snapshot.port`）。
- 空态：`等待同一网络中的设备` / `在另一台电脑打开 LANLink，保持同一 Wi-Fi 即可互相发现。`
- 设置页提示：只保留必要说明，不再解释 MAC。

## 3. 行为与边界

- 始终监听：应用启动即监听；无「关闭功能」入口；启动失败时设置页顶部显示错误（保留 `last_error` 告警），不再显示运行状态点/开关。
- 设备名：编辑后立即 announce；对端未备注时更新显示名，对端备注优先于原名（本地备注表 `peer_remarks` 不广播）。
- 端口显示：`snapshot.port`（运行中才有值）；设备名后紧跟 `· 端口`。
- 聊天头部：不显示在线/离线文字与绿点；IP 只显示 `peer.ip`，不显示端口；备注存在时 `原名 · IP`，否则 `IP`。
- 提示音：播放 `src/assets/sounds/chime-done.mp3`（从本机 `dsh-chime` 插件提取，MIT）；仍只对 `kind==='message' && direction==='in'` 播放；免打扰共享开关不变；首次用户手势后 `Audio.play()` 解锁。
- 「接收文件前需要确认」：后端不再提供设置命令，`require_accept` 固定 false，始终直接接收；前端删掉设置项组件。
- 删除/右键/托盘/未读/加密等上一轮行为不回退。

## 4. 接口契约变化

- 删除命令：`lan_share_set_enabled`、`lan_share_set_require_accept`。
- `lan_share_snapshot` 的 `enabled` 始终为 `true`（兼容保留）；`require_accept` 字段保留但恒为 `false`，后续可删。
- 其余命令/事件不变。

## 5. 验收

- `cargo test` 全绿；`npx vue-tsc --noEmit`、`npx vite build` 通过。
- 手动：设置页无标题/返回；端口在设备名后；无在线绿点；IP 不带端口；发消息响 `bip-bop` 完成音；左栏底部无「设置/运行状态」；标题 LANLink；整体无生硬分割线。
