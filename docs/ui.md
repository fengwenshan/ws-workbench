# 界面规范（Developer Minimalism）

规则文件是 `AGENTS.md` 第 10 节；本文是它引用的细表。改界面先读本文，评审按最后一节过一遍。

## 1. 一句话

现代开发者工具的壳：85%～90% 黑白灰 + 1px 浅边框 + 少量品牌蓝，像 Vercel / Linear 的控制台，不像「后台管理系统」。

判断标准：把两个模块的截图并排放在一起，去掉标题后应该分不出是哪个模块；**颜色只用来表达语义**（主操作、成功、警告、危险、选中），不用来装饰。

## 2. 颜色令牌

例外只有两处，且都已落地：技术栈 / VCS 标签统一中性色（不再用品牌色）；卸载窗口自带一套 `--un-*` 令牌，保持亮色（该窗口 820×560、不加载 `main.css`，见 `src/uninstall/styles.css` 头注释）。

## 3. 字体

- 字体栈走 `--font-sans`；等宽走 `--font-mono`，配合 `.mono` 类。
- 正文 13px / 1.6；辅助 12px；卡片标题 15px / 600；模块页标题 20px / 600；按钮 13px / 500。
- 中文不用粗体堆层级，靠字号和灰阶区分。
- IP、端口、MAC、路径、版本号、日志必须等宽（`.mono`）。数字用 `tabular-nums`。
- 表格 / 列表里的键和值：键用 `--text-secondary`，值用 `--text-primary`。

## 4. 间距、圆角、阴影、动效

- 间距 4px 网格：4 / 8 / 12 / 16 / 20 / 24 / 32；卡片内边距 16～20；页面左右留白 16～24。
- 两栏模块（项目 / VPN / LANLink）左栏宽度统一用 `--pane-left-width`（260），项目树默认宽度与之一致，切换工具时右栏起点不跳；两栏之间的间隙统一 4px。
- 模块直接铺满工作区，**工作区本身就是外框**：不再给模块套一层带 margin / 圆角 / 灰底的外层「画布卡」。两栏模块（项目、VPN、LANLink）两栏之间留 4px 间隙（项目模块用 4px 拖动条充当间隙）。
- 左侧 rail 是一张卡片：离窗口左 4px、下 8px，1px 边框，**左上/左下圆角 12**，右边 1px 线把 rail 和模块栏分开；当前工具没有模块栏时（清理、设置、收起项目树 / VPN 列表）rail 自己就是整张卡片，四角全圆。
- 左栏模块（项目树 / VPN 配置列表 / LANLink 设备列表）与 rail 拼成同一张卡：顶部贴住标题栏、下留 8px，顶/右/下 1px 线、**右上/右下圆角 12**，左边不画线（rail 的右边线就是分界）。
- 「系统」「设置」的布局和项目/VPN/LANLink 一样是两栏：左栏是一张卡片（宽 `--pane-left-width` 260，和 rail 拼成一张卡），栏头 56px 高、20px 品牌色图标 + 14px/700 标题，下面是分区导航；右栏同样是**一张内容卡**（右留 4px、下留 8px），卡片里再分内容，不能在卡片里又套一层带边框的框。
- 模块栏可收起：项目树、代理的配置列表、LANLink 设备列表、系统 / 设置 的分区导航，都是「再点一次同一个 rail 图标」收起、再点展开（切到别的工具再回来默认展开）；收起后 rail 自己就是整张卡片（四角 12），右栏内容卡补 4px 左边距、铺满到窗口右侧。
- 「设置」右栏是**一整列不分页**：所有分区（外观 / 检查更新 / 运行环境 / 附件上传 / 资源）顺序排下来，滚右栏就能一路看完；左侧导航跟着滚动自动选中当前看到的分区（文档站目录那种），点导航则平滑滚到对应分区，滚到底的时候选最后一节。
- 右栏内容区是独立卡片（参考 VS Code 编辑器区）：顶部贴住标题栏（不留上边距），**右留 4px、下留 8px**，左边就是两栏 4px 间隙；左栏收起或窄窗口自动收栏时，卡片自己补 4px 左边距。卡片画整圈 1px 边框 + 12px 四角圆角。
- 标题栏不画下划线：顶部边界交给内容区自己的边框和分栏线，避免出现两层横线；左侧图标栏（rail）、左栏列表都补 1px 顶边线，和右栏卡片的顶边对齐成一条。
- 两栏模块的左栏页头统一成同一套（项目 / VPN / LANLink 一致）：20px 主题蓝图标（与左侧 rail 同一枚图标，不另画）+ 14px / 700 标题 + 右侧 30×30 图标按钮（圆角 6、悬停浅灰底）；高度用 `--pane-head-height`（56），不画下边框，靠留白和列表分层。右侧内容区的标题行（项目页签、聊天页头）跟着用同一高度，保证左右标题在同一水平线。
- 笔记右侧「大纲 / 附件」侧栏用 antd `Tabs` 切换（和项目页「笔记 / 配置 / 上传」同一个组件）：页签行高 `--panel-header-height`（40）、14px，**既隐藏 `.ant-tabs-nav::before`，也隐藏 `.ant-tabs-ink-bar`**——不画整行分隔线、也不要会跟着切换滑动的下划线，选中只靠文字变品牌蓝；计数徽标写在页签标签里（`--bg-tag` / `--text-tag`，选中态 `--primary-soft`），收起按钮走 `#rightExtra`。
- 右栏内容区里不再一层层套卡片，只有最外层那张卡（rail + 列表 + 内容区）算卡片：
  - VPN 详情：「代理模式」「当前生效的分流」直接铺在页面上（`.proxy-mode-card` / `.preview` 去掉边框、背景、内边距），靠 24px 留白和 14px 标题分层；路由表不套外框，表头下与行间各一条 1px 发丝线。
  - 设置页：外观 / 检查更新 / 运行环境 / 附件上传 / 资源都是直接铺在页面上的段落（`.card` 只留 `padding: 0`），段落间距 24px；段落内部（如「运行环境 → 网络」）**不画分隔线**，只留 20px 留白，避免整行横线切碎页面。
  - 判据：内容已经在最外层卡里了，再加一层边框就是「框里套框」，别加。
- 分区导航（「系统」「设置」左栏）用 antd `Menu` 的 `mode="inline"`，条目对齐项目树的 `.list-item`：高 30、圆角 6、14px、选中 `--bg-active` + `--text-active` + 500；去掉 antd 默认的右侧对齐竖条和 `border-inline-end`，靠左栏卡片自己的 1px 右边线分界。不自己写导航控件。
- 圆角只有三档：`--radius-sm` 4（标签、小控件）、`--radius-md` 6（按钮、输入框、列表项）、`--radius-lg` 12（卡片、弹窗、面板）。不要再出现 8 / 9 / 10 / 14 / 16。
- 阴影只有 `--shadow-card`（可省）和 `--shadow-popover` 两级；优先用 1px 边框分层，别用阴影堆层次。
- 动效只做 `background-color` / `color` / `border-color` 的 0.2s ease；不做位移、缩放、发光。
- 描边是 1px 发丝线；分割线用 `--border-color`，不要用色块分隔。

## 5. 组件约定

- 一律用 `ant-design-vue` 组件，不自造同类控件。antd 主题在 `src/theme/antdTheme.ts`（`buildAntdTheme(dark)`），组件级 token 不够的部分在 `main.css`「antd 组件收口」里用变量覆盖。
- 每页主按钮最多一个（品牌蓝实心）；其余按钮是白底 + 1px 边框（`btn-secondary`）；危险动作用白底红字（`btn-danger`），不用大红底铺满。
- 状态不是靠颜色判断：错误、警告、成功都要带文字。`空态`用中性灰，不用插画。
- 图标：1.5～1.8 描边、16～20px、`currentColor`，不做多色图标。
- 选中态三件套：浅灰底（`--bg-hover`）+ 文字加深/加粗 + 需要时 2px 品牌蓝竖线；不再用「白卡片浮起 + 彩色投影」。
- 常驻小字解释默认不加（见 `AGENTS.md` 第 10 节）；确需说明时放 `title` / tooltip / placeholder / 空态。

## 6. 亮暗主题

- 三档：跟随系统 / 浅色 / 深色，默认跟随系统；入口在「设置 → 外观」（`Segmented`）。
- 状态在 `src/composables/useTheme.ts`：`mode`（system / light / dark）、`resolved`（light / dark），写入 `<html data-theme>`；偏好经 `safeStorage` 加密持久化（键 `ws-workbench:ui:theme`）。
- `App.vue` 的 `ConfigProvider :theme="antdTheme"` 跟着 `resolved` 切算法（`darkAlgorithm` / `defaultAlgorithm`）；`quick` / `clipboard` 独立窗口在 `main.ts` 里调 `initTheme()`，只吃 CSS 变量。
- 新增样式必须同时看两套主题：暗色下白色半透明、浅灰投影、浅色背景都会失效，改用令牌。
- 独立窗口（quick / clipboard / uninstall）不共享 JS 单例，各自初始化；uninstall 例外保持亮色。

## 7. 评审清单（改界面时逐条过）

- [ ] 只用了令牌，没有新增字面色值 / 渐变 / 毛玻璃
- [ ] 圆角只有 4 / 6 / 12，间距落在 4px 网格
- [ ] 一页只有一个主按钮；危险操作是白底红字
- [ ] 选中态是「浅灰底 + 加粗（+2px 蓝线）」，没有浮动/发光
- [ ] IP / 端口 / MAC / 路径 / 版本 / 日志是等宽
- [ ] 亮色、暗色都看过（`设置 → 外观` 切换后截图对比）
- [ ] 没新增常驻小字解释；删掉不影响理解的都删了
- [ ] 没有品牌色/装饰色：技术栈、VCS、文件类型标签都是中性色
- 分区标题行右侧只放操作按钮：标题 14/600 在左、按钮统一 `btn-xs`（24 高）；标题行下的说明文字（「网卡的 MAC 与全部 IP」「来源：…」「可下载的插件与扩展…」这类复述字段名的）一律不写。数据表格在窄宽度下**冻结首列和末列**（软件卸载：左「应用」、右「操作/卸载」`position: sticky`，表头 `sticky top` 吸顶），中间列横向滚动；滚动到中间时给冻结列补 1px 发丝线，两端贴合时不留线。
- 少用/危险/面向开发者的选项默认藏起来，靠隐藏手势解锁：开发者模式＝连点「当前版本」8 下（间隔 < 1.2s），解锁后才显示开关并给一条提示；已经开着就一直显示，关掉后立刻隐藏、下次进页面要重新解锁。解锁状态只存在内存里，不落盘。
